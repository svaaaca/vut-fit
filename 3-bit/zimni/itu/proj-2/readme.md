# ITU - Kuchařka

## Instalace

2. Přejděte do složky aplikace: `cd app`
3. Nainstalujte závislosti: `flutter pub get`
4. Vytvořte android projekt: `flutter create --platforms android .`
5. Spusťte aplikaci: `flutter run`
